# Unit Testing
## What is a "Unit"?
A small, testable part of a system, e.g. could be a specific function or routine, a specific sub-section of code, or module. Something that can be tested in isolation.
There are 2 traditional kinds of unit testing:
- White box testing (glass box)
- Black box testing
## White (glass) Box Testing
- glass-box = testing the internal structure and logic of a unit.
- "Look inside" the item to be tested:
	- examine internal structure of a program
	- use this to focus your design of test cases
- Look for logical decisions, independent paths through the program, loops, and the validity of data structures.
### Examples of white-box testing approaches
- Statement Coverage
	- Each statement must be executed at least once
- Branch Coverage
	- Each decision has each possible outcome tested at least once
- Path Coverage
	- Tests all the possible paths of the program
### Example "Unit" for us to test
```
Function(p,q)
	if((p+q) > 100) then
		print("Total Greater than 100")
	endif
	
	if(p > 50)
		print("P Value is Greater than 50")
	endif
End
```
